# F10.9 サポート閲覧（戦役Z-B）: 応答 DTO に資格情報らしいフィールドを持つが、代理中も閲覧を許す GET の例外表。
#
# 書式: <Controller の単純名>#<メソッド名>|<理由>（理由は必須。| は区切りにだけ使う）
# 番人 SupportAccessEnforcementGuardTest が、ここに無い該当 GET の @SupportAccessDenied 付与漏れと、
# もう該当しない行の残存を検出する。例外を足してよいのは、フィールド名が資格情報に見えても値が資格情報でない
# （第三者がその値を使っても本人として何もできない）ときだけ。
