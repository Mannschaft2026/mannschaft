# CMP-261113-1507 実機E2E・アリシゼーション記録

API のエラー本文を利用者の言語で返す戦役の、実機E2E とアリシゼーションの実施記録。個別の ID・認証情報は記載しない。

## 実機E2E（5 シナリオ・全合格）

| # | シナリオ | 結果 |
|---|---|---|
| 1 | 未ログイン（en / de の UI） | AUTH_004 のトーストが英語・ドイツ語で、日本語なし |
| 2 | ログイン済み（プロフィール言語 en、UI は ja を送信） | GDPR_003 が英語（プロフィール言語が優先） |
| 3 | 他テナントの ID・不存在 ID | 言語によってステータス・エラーコード・秘匿情報が変わらない |
| 4 | ja 退行 | ja・未指定は従来どおり日本語 |
| 5 | Accept-Language（en-US・未対応言語 fr・空） | en-US は英語、fr・空は日本語で 500 なし |

実機で見つかった欠陥は PR #4587 で是正した（de/es の訳の綴り、列挙値エラーの fieldErrors の日本語直書き）。

## アリシゼーション

約 3,500 の API を全走査し、error.message に日本語が残る件数は 0 件。走査で見つけた FE・fieldErrors 等の日本語直書きは後続の台帳行（CMP-261113-1507 に依存する行）へ起票した。
