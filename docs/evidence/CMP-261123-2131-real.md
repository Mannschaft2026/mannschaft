## 発見した欠陥（実装欠陥。修正は殿が判断。台帳行は作っていない）
1. 権限なしでも「大会を作成」ボタンが表示される。`pages/organizations/[slug]/tournaments/index.vue` の `data-testid="create-open"` に権限による `v-if` が無い。MEMBER・部外者・他組織 ADMIN の 3 視点で再現（押して送ると BE が 403 で拒否するので作成はできない＝セキュリティ上は守られているが、導線が出る）。期待: 作成権の無い者にはボタンが出ない。spec の「作成ボタンが出ない」3 件を `test.fail()` で固定（FE が出し分けたら外す）。

AC-3 の BE 400 は、前任の途中実行では 500（Data truncation）だったが、最新 main では 400 になっており欠陥ではなくなった（`test.fail` を外して通常の PASS に変更）。
