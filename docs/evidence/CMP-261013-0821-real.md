## ロール横断の結果（画面の文言）

- 権限あり（チーム ADMIN）: 本文（一覧）＋「回覧作成」が見える。
- 権限なし（チーム MEMBER）: 一覧は見えるが管理操作（作成・取消・削除）は出ない。
- 他テナント（他チーム ADMIN・非所属）: URL 直打ちでも回覧名は出ず、「情報を取得できませんでした」＋「再試行」のエラー面になる。作成ボタンも出ない。

## 条件の「権限取得の失敗時もエラー面が単一ルート」について

実環境で権限取得（`GET /api/v1/teams/{slug}/me/permissions`）を失敗させる正当な方法は見つからなかった。非所属・他チーム ADMIN でも権限 EP は 200（`roleName: null`）を返し、一覧 EP が 403 になるだけである。そのため画面に出るのは一覧コンポーネント側のエラー面（上表の R1-OTHER-TEAM-ADMIN / R1-OUTSIDER）であり、ページ側の権限取得失敗エラー面（`permissionsError`）は実機では踏めていない。ルート要素の単一性は PR #4731 の単体テスト（`circulation.spec.ts`）が担保している。ネットワーク遮断などのモックで代替することはしていない。
