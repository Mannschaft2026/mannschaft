## ペルソナと探索経路

| ペルソナ | 目的 | 観測 |
|---|---|---|
| 運営事務局の担当者（主催組織の管理者） | 連絡を出すとき、カテゴリで分類したい | 大会全体・ディビジョンとも作成フォームのカテゴリ選択に「お知らせ」「連絡」が出る。選ばず「未分類」のままでも投稿できる（`0859-oa-after-create.png`）。迷う点なし |
| 大会 ID を総当たりする者（部外者・他テナント） | 他人の大会の存在を探る | 実在の大会は 403 `TOUR_030`、不在の大会は 404 `TOUR_029` で、**カテゴリ一覧はスレッド一覧とまったく同じ応答**（28 組で不一致 0）。状態が分かれる点（存在の判別）はスレッド一覧と同じ仕様で、今回の契約の範囲外 |
| 引数を壊す者 | `scope_id=abc`、不正な `scope_type`、`scope_type=VILLAGE`（村 ID なし） | すべて 400 `COMMON_001`（スレッド一覧と同じ）。500 にならない |
| 他テナントの管理者 | 他組織・他チームのカテゴリを見る | TEAM・ORGANIZATION は 403 `COMMON_002`（回帰なし） |
| 未ログイン | 非公開の大会スペースを見る | 実在・不在とも 401（スレッド一覧と同じ） |
