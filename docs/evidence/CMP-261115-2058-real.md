## 根本原因（観測とコード読み）

掲示板の API `GET/POST /api/v1/bulletin/threads` ほか（グローバル方式）は、`scope_type` を `ScopeType.fromPathSegment()`（`backend/.../bulletin/ScopeType.java`）で解釈する。同メソッドは ORGANIZATION / TEAM / PERSONAL / VILLAGE しか受けず、列挙値にある `TOURNAMENT` と `TOURNAMENT_DIVISION` を不正値として `COMMON_001`（400）にする。このため FE を契約どおりに直しても、大会の掲示板は BE が受けない。起動ログにも `COMMON_001` の WARN が掲示板要求のたびに出ていた。

## 判定

**failed**。FE の契約ずれ（refId と scopeId）は解消し、チャットは動く。しかし掲示板の取得・既読・投稿が BE の 400 で成立せず、完了条件の「掲示板 API が 200」を満たさない。新規欠陥 D-F5 として CMP-261115-2058-exploratory.md に記録した（台帳には未起票）。
