## 発見した欠陥（実装欠陥。修正は殿が判断。台帳行は作っていない）
1. **割当済みチップを別の枠へドラッグして移動する導線が無い**（`frontend/app/components/shift/ShiftBoardMatrix.vue:56` が drop を常に `fromSlotId: null` で通知、`ShiftMemberChip.vue:3` は `cursor-grab` だが `draggable` が無い）。このため `board.vue:397` の `moveUser` 経路（`useShiftBoard.moveUser`）は画面から到達できない。移動は「×で外して付け直す」でのみ可能。期待: チップを別の枠へドラッグして移動できる（または見た目の `cursor-grab` を外す）。spec で `test.fail()` 固定。
2. **一般 MEMBER にも割当の追加ボタンとドラッグ欄が表示される**（`ShiftBoardCell.vue:23` の「+」と `ShiftMemberPool` に権限による出し分けが無い）。押して選ぶと BE が 403 で拒否するため割当はできない（認可は守られている）が、死んだ導線。期待: 管理者（ADMIN／DEPUTY_ADMIN）にだけ出す。spec で `test.fail()` 固定。

## 補足
- 当初、SUPPORTER を招待トークン（roleId=SUPPORTER）で作ると membership が MEMBER になり、メンバー一覧が MEMBER として返す別物の状態になった。実運用の SUPPORTER はフォロー（サポーター申請）で入るため、spec はチームの `supporterEnabled` を有効にしてフォローで作成している（招待経由の SUPPORTER 付与の挙動は本戦役の対象外。気づきとして記す）。
- 利用者はテスト専用ドメインのまま残る（削除 API が無い。他の real spec と同じ）。作成したシフト表・ポジション・チームは afterAll で削除し、残件 0 を SQL（読み取りのみ）で確認した。
- 是正前に割当へ紛れ込んだ利用者の洗い出しと掃除は CMP-261123-2132 の対象（本 spec の対象外）。
