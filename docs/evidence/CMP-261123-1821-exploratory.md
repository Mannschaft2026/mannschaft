実施 2026-11-24（是正 PR #4810、実機E2E PR #4833 の後）。住民ペルソナでシフトボードを実 UI から探索した。

## 本戦役の目的に関わる観測
- 認可は保たれていた。他チームのユーザー・非所属・SUPPORTER は割当に追加できず（BE は 400 SHIFT_049）、他テナントのシフト表は存在しないシフト表と同じ 404、slug 不一致は FE が取得失敗画面を出してメンバーを描画しない。
