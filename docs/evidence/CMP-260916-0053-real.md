# CMP-260916-0053 実機E2E・アリシゼーション記録（PR #4885）

- 実施日: 2026-11-25
- 環境: 検証用 BE（WSL、PR ブランチの jar）と FE（検証用ポート）。ローカルの MySQL を使用

## 実機E2E（合格）
- SYSTEM_ADMIN で `/admin/reports` を開き、Select の 5 状態（未対応・対応中・エスカレ・解決済・却下）を順に選ぶと、それぞれ該当する 1 件だけに絞り込まれた。リクエストは `status=…` 付きで 200。
- Select のクリア（×）で全 5 件に戻った。このときのリクエストは `status` なしで 200。
- API に不正な status（`BOGUS`・空文字・小文字の `pending`）を渡すと 400 になった。
- 部員と他テナントの利用者は、`/admin/reports` を開くと `/dashboard` へ遷移させられた。API は 403。

## アリシゼーション（短縮・合格）
- 絞り込みを全件に戻す操作は、「すべて」という選択肢ではなくクリアボタンで行う。操作は可能で、行き詰まりにはならない。
- 表示崩れ・エラーは観測されなかった。

## 後始末
- 投入した通報データは削除した。
