## 観察（欠陥ではない・FAIL にしていない）

- 税率入力は PrimeVue の InputNumber が 0〜100・小数 2 桁を入力時に強制するため、`percentToBasisPoints` の範囲外エラー表示（`tax-rate-format-error`）は画面操作では到達しない。150 は 100% に、`-5` は 5% に、`7.555` は `7.55%` になって入力欄に残る。保存される税率は入力欄に見えている値と一致する。
- 税額プレビューは税抜 3300・7.5% で「税額: 248」（`Math.round`）と出る一方、BE の保存値は税額 247・税込 3547（整数除算・切り捨て）で、プレビューと保存値が 1 円ずれる。本件（商品キー・税コードの選択式、税率の％入力）の受け入れ条件の範囲外で、別の台帳行（FE の税額プレビューを BE の丸めに合わせる課題）で扱われている。
- 既存の `price-revisions-real.spec.ts` の PR-09 系は、旧挙動の拒否文言「この画面を表示する権限がありません」を期待しているが、現在の `system-admin` ミドルウェアは `/dashboard` へ戻してトースト「アクセスできません／管理者権限が必要です」を出す。本 spec は現行挙動に合わせた。既存 spec 側の更新は本 PR の範囲外。
