# CMP-261117-0859 実機検証記録（大会連絡スペース画面の掲示板：スレッド詳細・新規作成の導線）

- 修正: PR #4603。`frontend/app/pages/organizations/[slug]/tournaments/[tId]/communication.vue` で、掲示板スレッドをクリックすると同じ画面内に詳細が開き、戻ると一覧に戻る。新規作成はフォームを開き、投稿後に一覧が更新される。スコープ（大会全体／ディビジョン）を切り替えると詳細・フォームの状態をリセットする。投稿権のない者の作成は 403 `TOUR_031` で、トーストで通知する。
- 実施日: 2026-11-18（JST、前日 2026-11-17 夜からの連続作業）。手段: Playwright（Chromium、実ブラウザ・モックなし）。ログインと前提データ作成だけ API を使い、対象操作は画面のクリック・入力・送信で行った。
- 環境: BE は **origin/main `51deace6fb`（#4603・#4601 を含む）から WSL native で bootJar を新規ビルド**（共通入口 `scripts/verification-run.mjs`、`--no-daemon`）して 8081 で起動。FE は同コミットの作業木（`npm ci`）の dev サーバー。実 MySQL・実 Valkey。CORS は OPTIONS で FE のオリジンが 200 になることを実測。
- 前提データは自前（`e2e-og-r30-` / `r30-` / `R30` の接頭辞）。
- スクリーンショット: `docs/evidence/screenshots/CMP-261117-0859/`

## 観測（欠陥候補。判定には含めない）

- **参加チームの代表・会員は、投稿権・閲覧権があるのに、この画面から掲示板に入れない**。画面は主催組織の配下 URL に作られ、連絡スペース一覧 API（「主催者向け」）が主催組織の管理者だけに 200 を返す。このため作成時の 403 `TOUR_031` は、権限が外された直後のような特殊な状況でしか画面から再現できない。詳細は `CMP-261117-0859-exploratory.md` の N-1 に記録した。

## 判定

**passed**（受け入れ条件のスレッド詳細・戻る・新規作成・投稿後の一覧更新・スコープ切替のリセット・403 `TOUR_031` のトーストを、実画面で確認した）。ただし参加チーム側の導線欠落（N-1）が残る。
