# CMP-261119-2032 調査記録: 行動メモの個人投稿を見つける導線

結論: 導線は欠落している（2026-11-23 確認）。

## 根拠

- 設計書 `docs/features/F02.5_action_memo.md` §5.4（514-525 行付近）に、公開した個人投稿の閲覧先の記述がない。686 行付近は /timeline に出る想定だが、/timeline/my（BE の findMyFeed）は scope_type=PERSONAL を含まない。
- BE には本人用の取得経路がある（feed?scopeType=PERSONAL、users/{id}/posts、posts/{id}）。
- FE にそれらを呼ぶ画面がない。frontend/app/pages/action-memo/closing.vue は公開後に /action-memo へ戻るだけ。

## 方針（マスター裁可 2026-11-23）

- 行動メモ画面から /timeline/{postId} への導線を追加する（CMP-261123-1201、P3）。
- 設計書を実態に合わせて是正する（CMP-261123-1202、P3）。
- 個人投稿一覧は任意とする（CMP-261123-1203、P5）。
