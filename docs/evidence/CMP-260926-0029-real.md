## 画面確認（アリシゼーション短縮版）
- ADMIN で UI ログイン → /teams/{slug}/member-profiles。ページ一覧（2025・2026・2027）が出て、2027 年度ページを開くと「前年度からメンバーをコピー」ボタンが出た。ダイアログ（コピー元ページ＝検証2025）で「コピーする」を押すと、POST copy-members が 200 で「24件のメンバーをコピーしました」のトーストが出た。DB は 2027 が 1→25 件、重複なし。
- MEMBER で同じ URL: 一覧と「メンバーを見る」は見えるが、「新規ページ作成」「カスタム項目」「前年度からメンバーをコピー」「一括登録」は出ない。
- 他テナントのユーザーが同じ URL を直打ち: 「情報を取得できませんでした」の画面になり、メンバー紹介の API 呼び出しは発行されなかった。
- メンバー検索 lookup は FE の `useMemberProfileApi.lookupMembers` に定義はあるが、ページ・コンポーネントからの呼び出しは見つからなかった。画面から lookup を叩く導線は現状無い（API のみで確認）。
