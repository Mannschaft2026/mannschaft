## 新規欠陥・疑い（修正はしていない。台帳には未起票）

- **N-1（導線の欠落・中〜高）**: 参加チームの代表・会員は、API では連絡スペースの掲示板を閲覧・投稿できる（チーム代表は投稿も可）のに、**画面から入れない**。連絡スペース画面は主催組織の配下 URL にあり、チームのトップ画面からのリンクもなく、さらに連絡スペース一覧 API が「主催者向け」で、主催組織の管理者以外には 403 を返す（組織の一般会員・部外者・他テナントも同様）。結果として、設計上の主な投稿者である参加チーム代表が使えない。画像: `0859-ta-open.png`、`expl-p2-team-top.png`。
- **N-2（軽微）**: 作成失敗のトーストが原因を伝えない。投稿権なし（403 `TOUR_031`）も長すぎるタイトル（400）も、同じ「作成に失敗しました」になる（受け入れ条件の「トースト通知」は満たす）。
- **N-3（軽微）**: スレッド詳細が URL に反映されない。再読込・共有・ブラウザの「戻る」で詳細状態を失い、前のページへ離脱する。
- **観測（仕様どおり）**: 非閲覧者に対し、実在の大会は 403 `TOUR_030`、不在の大会は 404 `TOUR_029` と返り、大会 ID の実在が判別できる（スレッド一覧と同じ挙動で、カテゴリ一覧もこれに揃えた。方針判断は別件）。公開設定の切替が 2 つ並び、掲示板用かチャット用かの表示がない（既知。軽微）。

## 判定

受け入れ条件の範囲は問題なし。**N-1** が新規の導線欠落。
