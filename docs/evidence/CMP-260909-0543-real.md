## 実環境で起こせなかった失敗（明記）

- **500（サーバー障害）**: 共有 BE/DB を壊さずに実環境で起こせる正当な手段が無い（組織別の無効化フラグを切り替える API も無く、BE の起動フラグ変更は共有 BE の再起動を要する）。実機では未実施。
- **通信断（Playwright の `setOffline`）**: 試したが、dev server が画面遷移時にページ分割チャンクを取得するため、遷移自体が起きず（ダッシュボードに留まる）、対象画面の取得失敗を作れなかった。代わりに LOAD-04 で、取得リクエスト 1 本をブラウザ側で接続失敗にする障害注入を使った。**これは実 BE の失敗ではなく**（BE・DB には触れない。応答の中身も差し替えない）、再試行導線の確認用である。
