## 新規欠陥（台帳には未起票）

- **D-F5（2058 の修正の取りこぼし）**: BE の `ScopeType.fromPathSegment()` が `TOURNAMENT` / `TOURNAMENT_DIVISION` を受けない。グローバル方式の掲示板 API（カテゴリ・スレッド一覧・投稿・一括既読）が大会・ディビジョン スコープで常に 400。FE の契約修正（#4547）だけでは大会の掲示板は見えない。
  - 修正の方向（提案）: 同メソッドに両スコープを足す（パス方式の `/{scopeType}/{scopeId}/bulletin/…` も同じ解釈を共有しているため、足したときの影響範囲として他の呼び出し元の認可経路を確認する）。結合テストで、FE が実際に送る `scope_type=TOURNAMENT` の要求を通す。
  - 画像: `2058-admin-bulletin.png`、`2058-admin-division-bulletin.png`
- **派生（要確認）**: 上記が直った後に、`communication.vue` が新規スレッド・スレッド選択を扱わない点（コード読み）を画面で確かめる。

## 判定

**failed**（D-F5）。

- **N-1（導線の欠落）**: 大会の連絡スペース画面の掲示板に「新規スレッド」ボタンが表示されず、スレッドをクリックしても何も起きない（ダイアログも遷移も API 呼び出しも無し）。画面から投稿もスレッド詳細の閲覧もできない（投稿は API 直接のみ成立）。前回の「コード読み」の疑い（`communication.vue` が `BulletinThreadList` の `create` / `select` を受けていない）が、画面で確認できた。影響: 管理者が連絡スペースの掲示板を「表示」はできるが「操作」できない。画像: `2058-viewer-thread-click.png`。
- **N-2**: 閲覧者（大会主催の管理者）が `GET /api/v1/bulletin/categories?scope_type=TOURNAMENT&scope_id=<大会ID>` と同 `TOURNAMENT_DIVISION` で **403 COMMON_002** になる（スレッド一覧・投稿は通る）。画面では通知が出ずカテゴリの選択肢が空のままになる。影響: カテゴリ絞り込みが使えない。D-F5 と同じ系（グローバル API の大会スコープ対応の取りこぼし）の可能性が高い。

### 判定

**failed**（N-1、N-2）。D-F5 の中心症状は解消したが、導線の欠落（N-1）が残る。
