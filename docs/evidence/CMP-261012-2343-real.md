## 既知の欠陥（`test.fail()` で固定。別の台帳行で追跡）
管理者で開いても、画面が最初に呼ぶ API が BE に存在せず 404 になるページが 5 つある。入口ガード（本 CMP の対象）とは無関係の、FE→BE の未実装・パス不一致。権限なし・未ログインの 403/401 は期待どおりで、ガードの検証には影響しない。修正はしていない。spec の `KNOWN_ADMIN_API_DEFECTS` に台帳の行をコメントで記してある。
| ページ | FE が呼ぶ API | 管理者の応答 | 備考 |
|---|---|---|---|
| `/admin/campaigns` | `GET /api/v1/system-admin/discount-campaigns` | 404 | BE に該当 Controller なし。画面は「キャンペーン一覧の取得に失敗しました」 |
| `/admin/module-pricing` | `GET /api/v1/system-admin/module-pricing` | 404 | 同上 |
| `/admin/packages` | `GET /api/v1/system-admin/packages` | 404 | 同ページの `modules` は 200 |
| `/admin/storage-plans` | `GET /api/v1/system-admin/storage-plans`、`/storage-usage` | 404 | 同上 |
| `/admin/tax-settings` | `GET /api/v1/system-admin/tax-settings` | 404 | BE の税設定は `/api/v1/system-admin/billing/tax-codes` のみ |

再現: `e2e-admin` でログインし、上記ページを開く（または Cookie 付きで API を GET）。該当クラスの確認: `grep -rn "system-admin/tax-settings" backend/src/main/java`（ヒットなし）。
