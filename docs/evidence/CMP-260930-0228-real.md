## ロール横断
- 正: 主催組織 ADMIN（e2e-admin）で全操作可（F1〜F5）。
- 負: チーム MEMBER（R1）で導線自体が出ない。作成・適用 API は 403。
- 他テナント: 非所属ユーザー（R2）は導線なし、API は全 403。
- 注記: エントリーモーダルは FE の `isAdminOrDeputy`（組織の ADMIN/副代表）限定。チームだけの ADMIN には導線が無い（要件側の判断事項。実装欠陥としては扱わない）。
- 注記: テンプレートの一覧 GET はチームメンバーに 200（設計どおり）。
